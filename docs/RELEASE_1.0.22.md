# Suite RRHH 1.0.22

- Control ahora compara **Trab. Real de Tempo − RUIDO de Partes Mensuales**.
  Trab. Día se conserva como total informativo y no interviene en Control.
- Se reconoce el encabezado Trab.Real / Trab. Real por nombre, independientemente
  de su posición. Si falta, se solicita una nueva exportación de Tempo; no se
  sustituye por trabajo diario ni se supone cero.
- Se conservan tolerancia, reglas de selección, guiones y colores. El detalle
  del trabajador, la ayuda y los dos informes explican el nuevo origen.
- Menú principal con tarjetas verticales compactas y disposición adaptable.
- Exportar/importar comparaciones completas en formato .rrhh para compartirlas
  y revisarlas con filtros y detalle, sin necesitar los Excel originales.
- Importar no recalcula ni modifica resultados. Cada comparación mantiene sus
  explicaciones originales, incluso si las reglas cambian en otra versión.

Los archivos .rrhh contienen datos de trabajadores y no están cifrados. Enviar
solo a destinatarios autorizados, mediante los canales corporativos aprobados.

La actualización conserva el runtime y la configuración de cada equipo. No
incluye libros de trabajadores, credenciales ni archivos de validación locales.
