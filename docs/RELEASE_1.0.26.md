# Suite RRHH 1.0.26

- El Comparador de Tempo reconoce `1130-HE30%` y `1166-HE30%` como cabeceras de horas al 30 %. Las exportaciones de ambos formatos se pueden seguir comparando con las mismas reglas de cálculo.
- Si faltan columnas en el archivo de Tempo, el aviso identifica las que faltan.

Para actualizar una instalación existente, abre Suite RRHH y acepta el aviso o pulsa «Buscar actualizaciones».
