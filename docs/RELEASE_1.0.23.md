# Suite RRHH 1.0.23

- Botón Compartir con fondo, borde y flecha visibles, coherente con Vista.
- Estilos centralizados para ambos botones desplegables, con estados de foco,
  pulsación, cursor y deshabilitado.
- Ayuda al pasar el cursor y apertura comprobada con ratón y teclado.

Para exportar, terminar la comparación y pulsar **Compartir → Exportar
comparación completa…**, en la parte superior derecha de los resultados.

No cambian los cálculos, los informes ni el formato .rrhh. Se mantienen las
funciones de 1.0.22: Control con Trab. Real, menú vertical e intercambio de
comparaciones completas sin recalcular los resultados importados.
